# 《我的世界盒子》模组工程（Fabric 1.20.1）

- 正式名称：**《我的世界盒子》**｜modid `livingcity`｜包名 `com.livingcity`｜版本 1.2.1-dev.10
- 底座：Minecraft 1.20.1 / Fabric Loader 0.16.10 / Fabric API 0.92.6+1.20.1 / Yarn 1.20.1+build.10 / Loom 1.7.4（版本值以 `gradle.properties` 为准）
- 定位：以城市模拟为内核、Minecraft 世界为舞台的氛围增强模组。玩家不是市长，城市自行发展。
- 本仓库包含城市模拟核心、MC 传感与表演层、网页地图和蓝图转换器。

> 旧版 README 是 Fabric 模板教程（Tutorial Mod），已归档至 `../90-历史归档/README-tutorialmod-旧版.md`，不作现状口径。

## V1.2.1-dev.10 未加载建筑现场与检测窗口

住宅、港口及拆除工作接入临时区块检测队列。后台先读取已保存的地图记录和安全的原版种子估算，为有限数量的候选区排序；随后向 Minecraft 申请临时 FULL 级区块加载，异步等待现场就绪。真实地形检查、道路衔接、平滑、建筑放置及拆除继续使用主线程预算。进行中的工地可在暂停、卸载和重读后重新取得所需区块。完成后更新实景地图并释放请求。

城市手册 Shift＋右键 →「区块检测」，或者实时网页「世界工具 → 建筑区块检测」，可查看活动现场、等待城市、后台初筛运行数、已就绪与直接请求区块数、任务阶段、完成及超时数。默认启用，2 个同时处理的现场、1 个初筛线程，两项均可调 1～4。直接请求总上限 128 区块，Minecraft 的生成依赖另计。每个现场有加载等待和检测租期，连续触及 MSPT 守卫时让出请求，时钟暂停、关闭功能与世界退出时释放请求。

检测配置和搜索游标随 registryVersion 8 保存，旧档按默认设置迁移。临时加载请求和后台任务不保存。独立服务器验收先卸载所有目标区块，再确认无人靠近时两城建房、一城建港、并发设置生效、暂停释放、施工续跑以及现场卸载。网页验收覆盖计数、任务列表、开关和并发／线程设置。

## V1.2.1-dev.9 多城资源调度与岸线选址修复

资源发现、建筑选址和现场写入使用独立轮转位置。旧版在大量城市等待选址时，一轮遍历会回到同一座城，导致后面的城市反复拿不到森林搜索与选址机会。资源发现现在每刻轮到一座城市，不依赖是否存在已备料工程，也不被现场施工守卫阻断，不申请区块加载。

港口勘测在住宅施工期间继续推进，使用已加载领地中的单方块入口和四个朝向，中心附近优先。码头地板按实际水面上方一格确定，道路可衔接低一至两格的岸边。住宅缺料时可以先勘测港址，住宅备料足够后再支付港口工时与材料。采石场占位会避开已选港址，已有港口不会重复下单。

城市查看器和网页需求面板显示资源搜索、缺料及港口状态。当前粮食仍由核心的抽象口粮工时和剩余工时生产，不要求实体农田；界面明确展示这一现状。已迁出的居民保留实际账本结果，更新版本不会自动补回人口。

## V1.2.1-dev.8 自动港口、船运贸易与拓殖验收

现场施工每刻轮转处理，在 4 毫秒的时间预算内推进道路、整地和建筑方块。城市手册的施工批量决定每刻总方块上限。达到地图性能设置中的守卫门槛时让出时间，默认门槛为 45 MSPT。

临水城市在有至少 8 名居民、已有和排队住房能承接人口、口粮未发生危机时，会寻找可接道路的港址。港口需 8 木材、4 石材及 12 产业工时，现场使用 20×18×16 的真实港口素材，地板高度为 3。港口可跨占空闲的邻接水域区块。地板下的桩基按蓝图放置，水面保持可通航。

已落地港口参与当前存档的石材采购。买家比较报价、运费、船期与本地采石方案，卖家保留自用储备后报价。航次、船位、资金与到港记录可从实时地图「智慧与生命 → 港口贸易」查看。货物、货款和在途状态随城市存档保存，游戏外导入可接着运行同一份贸易状态。

已加载水域内的航次以原版船模型表演，全世界最多同时显示 32 艘。航次位置由城市周期决定，区块卸载后继续按账本航行，临时船实体由加载状态重建。

拓殖队到达后，服务端使用全世界共用的一个临时目标加载请求完成现场验收、放置市政厅和建城，完成后释放请求。网页仍可查看目标。地图记录可供陆地初筛，现场验收继续检查实际支撑、净空和实体。

实时地表按水深分为浅海（1～5 格）、近海（6～10 格）、深海（11 格及以上）。附近记录自动更新深度。旧的远处实景可通过「补绘已保存区域」重新读取水深。

## V1.2.1-dev.7 原精度地表与高度阴影

实时地图的实景按 1×1 方块记录，种子估算按固定 4×4 方块采样。缩放复用原精度瓦片，地图中的建筑顶面、道路和小型地形保留实际方块颜色。草、高草丛和花朵等小型植物会在读取地表时略过。树冠保留。北面和西北面较低时提亮，较高时压暗，瓦片交界也读取邻接地表。

安装后用世界地图 Ctrl＋右键打开实时网页。附近实景自动重采样，远处以前探索过的区域可在「世界工具 → 地图性能」点「补绘已保存区域」。新版缓存使用 `data/livingcity-map/overworld-v2/`。首次绘制按照原精度逐步填充。缩小后再放大复用同一份地表。

## V1.2.1-dev.6 地表地图与补绘

在主世界手持世界地图，按 Ctrl＋右键。实时网页的「世界工具 → 地图性能」可设置城市边界预绘半径、附近实景半径、后台线程数和每刻预算。点「补绘已保存区域」，地图会从当前存档读取以前探索过的区块，显示读取和绘图进度。已绘地表和瓦片缓存随存档保存在 `data/livingcity-map/overworld-v1/`。

同一地表上以实际记录覆盖种子估算。点选子格可查看 Y 高度、来源和已测地表方块。默认预绘边界外 8 区块，记录玩家附近 4 区块，最多使用 2 个地图后台线程。主线程任务默认每刻最多使用 2 毫秒的地图预算，测得刻耗时达到 45 MSPT 时会等待。实时地图随 Minecraft 服务器运行，手动打开游戏的暂停菜单时也会暂停地图生产。

## V1.2.1-dev.3 地图工具栏

网页地图默认显示「世界工具」，可以查看国家数、城市数、市民人口和可用床位。实时与离线会话显示各自的城市时钟。离线地图还能导入存档、扫描种子并修改扩张规则。再次点当前页签，或点「返回世界」，回到默认工具栏。

- 「世界塑造」在离线模拟里提供建城和建港。先在图上选中目标区块或子格，再执行工具。
- 「智慧与生命」提供城市需求、仓库、外交与战报、港口贸易、拓殖队和图层。右键本城或其他城市的领土可直接打开该城的需求。
- 「其他」提供存档快照、离线示例以及下载和恢复离线快照。实时地图随当前游戏存档显示；离线示例在独立的离线会话使用。
- 「动物、生物与怪物」「自然与灾难」「毁灭与混乱」保留分类入口。

## V1.2.1 陆战测试

在离线地图的「其他」点「加载陆战示例」，再回到「世界工具」用「单步」推进。「智慧与生命」中的野战军可以点击定位，地图选中的无主区块中，虚线轮廓是军队的四区块视野。「最近战报」显示改道、双方投入、战损和城市易主。下载的离线快照可以从在途位置继续模拟。

国家统一填色，较深边线分出各城市。地图用金冠定位国王、银冠定位市长，旗帜定位将军。每座城保有一份常备军编制，停战或战败后回城整补。陆战占领完成时，城市连同领地与账本转交胜方，军队可从已夺取的城市补给，再找下一处战线。

游戏内用 `/city nation list` 查国家编号。房主或管理员可以在实时地图的「智慧与生命 → 外交与战事」操作，也可用 `/city nation war declare 1 2` 宣战、`/city nation war truce 1 2` 停战撤军。常备军至少两人、粮草足够且敌城边界有可达入口时可以出征。停战期限为 80 个世界周期。

## V1.2 实时世界地图

在本机单人存档里，从创造物品栏的「工具」取得世界地图，也可用指南针与空地图合成。手持世界地图按 **Ctrl＋右键**，默认浏览器会打开当前主世界的实时地图。页面可查看城市、国家、领地、工程和在途拓殖队。附近已加载地形按 4×4 子格绘制。

用网页调节倍率、暂停或单步时，指令交给当前存档的城市时钟。手动打开 Minecraft 暂停菜单时，页面会显示菜单暂停。退出存档后，实时页面断开，进入下一份存档后可用道具重新打开。

游戏外的离线地图可用 `tools/start-offline.cmd 8769` 启动。导入的存档会另外运行一份模拟进度，适合脱离 Minecraft 试跑。

## V1.2 国家与陆路拓殖

玩家独立建立的城市各自立国，它也是该国首都。由拓殖队建立的城市继承母国，使用自己的领地和城市账本。手持城市手册 Shift 右键，打开「国家」页看国名、成员数、母城、拓殖坐标和剩余周期。新世界默认自动派队，旧档升级后可在这一页启用。

在测试世界内找一座附近有开阔陆地的城市。使用管理员命令准备母城，留四张以内空床。若要立即检查派队条件，站在这座城里运行下面四条命令。

```mcfunction
/city debug population 32
/city debug food 4000
/city debug materials 96 64
/city nation dispatch
```

用 `/city nation` 看目标 X、Z，保持城市时钟运行，去目标附近加载区块。验收通过时放下市政厅，新城获得六名居民及随行物资。用 `/city nation list` 比较各国成员数。母城可用 `/city nation cancel` 撤回在途队伍并收回人员和物资。

## V1.1 开发包实测

用测试存档副本启动。旧的单城数据首次保存时会迁移到多城格式，回到旧版时请使用原副本。此开发包支持主世界，沙漏倍率对同一存档内所有城市生效。

1. 在未归属区块放置市政厅并右键建城。用 `/city list` 查看编号，站在各自领地内用 `/city info` 查看当地账本。领地外的查询选择最近的市政厅。
2. 市民优先出现在已加载的本城原版土径上。无路时在市政厅附近寻找安全站位。市政厅及周围一圈保留给入口，拆除后原城保留。原址重建可以恢复入口；迁址时先放新市政厅，再执行 `/city relocate <城市编号> <x> <y> <z>`。
3. 保存世界后用现代浏览器打开 [游戏外调试地图](tools/city-map.html)，选择该世界的 `data/livingcity_city.dat`。色块标记领地，虚线框标记工程用地。放大地图可查看建筑图标和名称，侧栏按城市显示仓库与施工状态。
4. 要比较两次扩张，将第一次保存的 DAT 复制出来。第二次保存后，在地图里分别打开当前档和旧快照。V1.1 dev.1 的多城档可直接比较疆界。打开旧单城档时可以查看建筑和市政厅。

5. 工程付足工时与材料后进入现场施工队列。到工地区块附近观察四床住宅、水井和广场逐步落地。采石场使用空蓝图，耗 12 木材和 8 工时，完工后随每周期实际拨给的工时产石。

6. 用创造物品栏里的城市手册（或 /give @s livingcity:city_handbook），手持时 Shift 右键。「世界规则」里默认开启定时扩张，每座有居民的城市每 20 个城市周期最多认领一个相邻区块，受领地上限约束。关闭定时扩张后，按工程用地需要认领。表演设置控制全服市民实体上限和施工批量。调试页可以查看最近城市的周期和工地进度，也可以暂停、单步和调速。
7. 双击 tools/start-offline.cmd，在浏览器打开 http://127.0.0.1:8766/。在「从存档继续」里选择同一世界根目录的 level.dat 和 data/livingcity_city.dat，然后点「导入并暂停」。也可以用种子创建新模拟。测试会话在内存运行，地形预览使用原版 1.20.1 主世界采样。导入时读取存档里的定时扩张设置，旧档和新种子默认开启。调试地图也支持直接读 DAT 快照。

8. 手持城市查看器右键。点方块查看该区块归属城市，在空气中右键查看脚下所属城市。网页可右键城市领土或点击城市卡片上的「查看需求」。
9. 要拆除有快照的建筑，站在所属城市里，用 `/city info` 查建筑编号，再执行 `/city demolish <编号>`。快照从 dev.7 开始记录，只恢复蓝图覆盖前、整地后的方块。拆除共用施工预算，暂停城市时钟时也会执行。
10. 在「城市手册 → 世界规则」开启「村民自动入籍」。首次开启和原版村民求职都会请求检查。已加载且站在任一城市领地内的未交易成年村民会分批入籍，每轮后共用 100 服务器刻冷却。用 `/city info` 查看人口，用 `/city chronicle` 查看入籍批次。
11. 查看器和地图将可用床位、待落地床位分别列出。现场完工后床位和公共设施服务才生效。已有的已付工单在载入时按建筑锚点区分，保留项目进度。查看器和手册会显示现场施工状态，服务器每刻达到 45 毫秒时标记暂缓。

## 港口贸易离线试验

在离线调试地图的「其他」点「加载三城贸易示例」，回到「世界工具」用「单步」或「1 周期/秒」推进，在「智慧与生命」观察比价、冻结货款、装船和交付。也可导入自己的存档，在「世界塑造」选中城内岸边的陆地子格并点击「在所选子格建港」。缩放可看清 4×4 子格，点击子格可查看水陆、群系和方块坐标。「其他」中的「下载离线快照」和「恢复离线快照」能保留航程与现金。

当前贸易只在离线模拟运行，浏览器的岸线是用种子采样的地表估算。港口使用空蓝图，船由地图标记表现。Minecraft 中的建筑和船实体接线留待后续试验。

## 二、城市模拟核心

城市模拟核心在 `sim/`，使用纯 Java 17，通过 `build.gradle` 直接编入本工程。克隆仓库后即可构建完整模组和离线地图。

```gradle
sourceSets { main { java {
    // 无头模拟核心（纯 Java 17，零 MC 依赖）直接参与编译，保持单一源码
    srcDir file('sim/src')
} } }
```

核心可脱离 Minecraft 独立编译与跑回归。MC 侧提供传感输入并放置蓝图。材料生产和扣费在核心账本结算。

蓝图转换器位于 `tools/blueprint-converter/`，可独立将 Axiom/Litematica 等素材转换为 `.bp`。本机原有的 `../03-代码/livingcity-sim/` 和 `../03-代码/blueprint-converter/` 已改为指向仓库内对应目录的 Windows 目录联接，旧路径与新路径编辑同一份源码。
