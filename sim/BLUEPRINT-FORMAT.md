# 蓝图格式规范 V1（资产管线契约）

> 关联笔记：《事件系统-建筑完整性与工程物化管线》《城市形态与道路》《模拟器与投影层》
> 用途：定义建筑蓝图的标准格式，供「网上开源蓝图 → 转换器 → 模组资产」管线使用。**M1 无头测试台不需要任何蓝图**；本格式在 M3（物化管线）才成为关键路径——资产收集/转换可以从现在开始并行做，正好是可以外包给其他模型或人工的任务。

## 1. V1 需要多少蓝图（首批清单）

| 类别 | 数量 | 说明 |
|---|---|---|
| 住宅变体 | 4~6 | 小/中/大，含床（床位数登记进账本 bed_count） |
| 水井变体 | 2 | 覆盖 30 人 |
| 广场变体 | 2 | 覆盖 30 人，含集会空地 |
| 道路 tile | 2 种 | 土路 / 石板路（autotile 拼接件） |
| 城墙件 | 2 种 + 城门 1 | 直线段 / 转角段 |

**外观变体不新增机制类型**——「3 种建筑类型」红线限制的是机制，皮肤随便加（每变体一个 id）。

**红石机器蓝图：不需要功能性的。**动态部件不模拟（完整性账本直接忽略），工厂内部是布景——所以只要「长得像机器」的静态外观，活塞/漏斗/红石灯越多越好，全部归入动态部件类。**能跑的红石机器蓝图对 V1 无价值。**

## 2. 格式（纯文本，一行一方块）

```
# 元数据（键值对，#开头为注释）
@id          house_small_01
@kind        HOUSE            # HOUSE / WELL / PLAZA / ROAD / WALL / GATE
@size        7x5x9            # 宽x高x深（方块数），footprint 必须 ≤ 区块两级单元
@floor_y     0                # 可省略，最低方块层为 0。第四层地板填 3
@entrance    3,0,8            # 入口坐标（相对原点），必须落在 footprint 边缘、贴道路
@origin      bottom-center    # 放置锚点：地基平面中心
@author      xxx              # 来源与许可证（见 §4）
@license     CC-BY-4.0
# 方块清单：x,y,z 方块id 分类
# 「方块id」允许带方块状态后缀 namespace:path[prop=value,...]（无状态方块裸写）。楼梯/半砖/朝向床没有状态无法回放。
0,0,0 minecraft:oak_planks S
0,1,0 minecraft:oak_planks S
3,2,7 minecraft:torch D
1,0,4 minecraft:chest C
...
```

分类标记（对应完整性账本的蓝图方块二分）：

- **S = 结构方块**：进完整性账（每块 1 点），损坏判定/维修计价看它。
- **D = 动态部件**：活塞/红石/作物/流体/火把等，账本完全忽略。
- **C = 容器**：箱子/木桶等，**放置时跳过不放**（玩家私塞物品不动、账本无真库存——整蓝图回放无副作用的前提）。

## 3. 三条硬规则

1. **依赖序**：清单顺序 = 放置顺序，支撑块在前、依附块在后（墙→火把，地板→床）。转换器负责拓扑排序，模组放置时按行序回放，不重排。
2. **地板平面**：陆地蓝图的 `@floor_y` 层必须完整。整地把该层贴合工地，地板下的显式方块作为地基放置。蓝图方块、入口仍用最低层为 0 的本地坐标。港口转换允许稀疏地板和桩基，游戏内的岸线施工另行接入。
3. **床登记**：`@beds N` 元数据声明床数（原版床占两格算一张）；放置成功后传感层对账校正。

## 4. 许可证红线（收集前必看）

- ✅ **CC0 / CC-BY**：可用，CC-BY 需在模组 credits 里留名（`@author`/`@license` 字段就是为此设的）。
- ❌ **GPL 资产**（MineColonies 模板等）：不搬——已裁决「GPL 传染隔离：借想法不借代码，资产文件无论如何不搬」（《模拟器与投影层》§4）。
- ❌ 来源不明 / 无许可证声明：不用。
- 转换器工具本身建议自写（读 .litematic/.schematic/.nbt 的 NBT 解析约 200 行，零依赖可实现），不引入第三方 NBT 库（零依赖红线）。

## 5. 转换管线

```
开源蓝图(.litematic/.schematic/.nbt)
  → 转换器（一次性工具：解析 NBT → 方块分类查表 → 拓扑排序 → 输出本格式）
  → 人工抽查（入口位置/床数/尺寸是否合规）
  → 模组资产目录（每建筑类型一个文件夹，变体平铺）
```

分类查表：模组内置方块标签白名单（结构/动态/容器三张表），转换器与运行时共用同一份。
